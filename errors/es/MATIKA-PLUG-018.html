Error MATIKA-PLUG-018

  • Componente: MATIKA (matika)
  • Repositorio de origen: manomatika/matika
  • Gravedad: error
  • Ruta de registro: aggregate
  • URL canónica: https://manomatika.github.io/error-docs/errors/es/MATIKA-PLUG-018

Mensaje

Un AppLug registra un id que ya pertenece a otro AppLug, o una ruta (método y ruta) que ya sirve el anfitrión u otro AppLug; el AppLug no se carga

Solución

Todavía no se ha publicado una guía de solución para este código. Consulte el mensaje anterior y los registros de la aplicación del componente y la facilidad indicados.
