Error MATIKA-PLUG-015

  • Componente: MATIKA (matika)
  • Repositorio de origen: manomatika/matika
  • Gravedad: error
  • Ruta de registro: aggregate
  • URL canónica: https://manomatika.github.io/error-docs/errors/es/MATIKA-PLUG-015

Mensaje

La declaración settings_ui de un AppLug no es válida, o uno de sus ids de campo colisiona con un ajuste del núcleo o con el de otro AppLug; el AppLug no se carga

Solución

Todavía no se ha publicado una guía de solución para este código. Consulte el mensaje anterior y los registros de la aplicación del componente y la facilidad indicados.
